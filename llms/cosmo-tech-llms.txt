# Cosmo Tech

> Cosmo Tech is a predictive and prescriptive AI-simulation platform for industry (digital twins). The open-source Cosmo Tech Cloud Platform API models organizations, workspaces, solutions, datasets, runners and runs so teams can configure and execute large-scale what-if simulations across supply chains, assets and operations.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public OpenAPI and repositories (github.com/Cosmo-Tech/cosmotech-api, MIT). Auth is OAuth2 / OIDC via Keycloak. Errors are status-only (400/403/404/422). Pagination is page + size.
