Cosmo Tech is a predictive and prescriptive AI-simulation (digital twin) platform for industry, based in Lyon, France and backed by Insight Partners. Its open-source Cosmo Tech Cloud Platform API (Kotlin, MIT) lets teams model organizations, workspaces, solutions, datasets, runners and runs, then configure and execute large-scale what-if simulations across supply chains, asset investment planning and enterprise operations. The API is modular across seven service specs (organization, workspace, solution, dataset, runner, run, meta), authenticates via OAuth2 / OpenID Connect (Keycloak), and ships auto-generated TypeScript and Python clients plus the Babylon CLI.

**Areas:** Company · Simulation · Digital Twin · Artificial Intelligence · Supply Chain · Predictive Analytics · Industrial

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Cosmo Tech: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
